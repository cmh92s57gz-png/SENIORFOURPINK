# SENIOR FOUR PINK 2026 — GitHub Pages

A static HTML/CSS/JavaScript class magazine website.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload **the files inside this folder** so that `index.html` is in the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site.

No Python, Vercel, Node.js, or build command is required.

## Add photos
Put photos in `assets/` and edit `index.html` to add image elements where you want them.
